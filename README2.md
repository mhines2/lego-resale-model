# LEGO Resale Price Prediction

This project predicts the resale price of LEGO sets using regression models trained on attributes like release year, theme, number of pieces, and MSRP.

## How to Reproduce

1. Open the notebook in Google Colab:  
   [Open in Colab](https://colab.research.google.com/drive/142sCFq0J2VYcfJ9wWoi64PaTooXyQj4m?usp=sharing)

2. Once the notebook loads, click **Runtime > Run all**.

3. When prompted, upload the `sets.csv` file to continue.

That's it — the notebook will take care of data cleaning, modeling, and evaluation automatically.
